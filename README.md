# 🌿 PlantAI – Нейронная диагностика растений

PlantAI – это сервис на основе искусственного интеллекта для автоматической детекции и классификации болезней растений по фотографиям листьев.  
Система определяет **вид растения**, находит **каждый лист** на снимке и **диагностирует заболевание**.

---

## 🚀 Возможности

- **Детекция листьев** – YOLOv8 находит каждый лист на фотографии, игнорируя фон.
- **Классификация вида** – EfficientNet-B0 определяет культуру (яблоня, томат, кукуруза и др.).
- **Диагностика болезни** – ResNet-50 для каждого вида предсказывает конкретное заболевание (фитофтороз, парша, ржавчина и т.д.).
- **Русский интерфейс** – все подсказки и названия болезней переведены на русский язык.
- **Поддержка камеры** – можно сделать снимок прямо с телефона или ноутбука.
- **Готовый веб-интерфейс** – симпатичный киберпанк-дизайн с анимациями и карточками результатов.

## 📥 Установка и запуск (локально)

1. Клонируйте репозиторий:
```bash
git clone https://github.com/your-username/PlantAI.git
cd PlantAI
```

2. Создайте виртуальное окружение и установите зависимости:
```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

3. Скачайте модели (нужен токен Яндекс.Диска):
   - Создайте файл `.env` с переменной `YANDEX_DISK_TOKEN=ваш_токен`
   - Запустите:
```bash
python download_models.py
```

4. Запустите приложение:
```bash
python app.py
```
Откройте браузер и перейдите на `http://localhost:5000`.

## ☁️ Деплой на Hugging Face Spaces

Проект уже настроен для деплоя на Hugging Face Space (Gradio SDK).  
Модели хранятся в отдельном репозитории и автоматически скачиваются при старте.

1. Создайте Space с SDK **Gradio**.
2. Загрузите файлы `app.py`, `model_adapter.py`, `requirements.txt`.
3. Загрузите модели в репозиторий на HF Hub.
4. Space автоматически соберётся и запустится.

## 🧠 Использование

1. Загрузите фотографию листа (или сделайте снимок камерой).
2. Нажмите **Анализировать**.
3. Система покажет:
   - Размеченное изображение с bounding boxes вокруг листьев.
   - Карточки с видом растения и диагнозом для каждого листа.
   - Процент уверенности модели.
